# Forever Loot Sparkles - Herbs & Ores

Companion addon for Forever Loot Sparkles. The original addon is not modified.

- With Forever Loot Sparkles 2.x: brings back the sparkles on herbs, ore veins, quest objects and
  corpses with loot (taken over from Forever Loot Sparkles 1.3.1), with "Safe self-cast" (soft targeting
  pauses in combat and on living units) and an option to hide the nameplate under the sparkle.

- Colors the glints per category: Herbs, Ore veins, Quest objects, Corpses with loot.
  The color swatches sit next to the checkboxes on the Forever Loot Sparkles options page, with an on/off switch and a reset button below them.
  Saved per account in `ForeverLootSparklesColoringDB`.
- Translates Forever Loot Sparkles' options panel into German (deDE) and French (frFR),
  chosen automatically from the client language.

- Optionally hides the game's interaction icon over objects (all, or per kind: herbs, ore veins,
  quest objects, corpses with loot, other objects, NPCs). The sparkles stay.

## Limitations

- Only the glints Forever Loot Sparkles draws itself (herbs, ore, quest objects, corpses on approach)
  can be colored. The game's own loot sparkle on quest items is drawn by the engine.
- The "restart the game" chat line and the addon list description of Forever Loot Sparkles stay English
  (they would need changes to its files).
- The texts are matched to Forever Loot Sparkles 1.3.1; a reworded string in a later version stays English.
