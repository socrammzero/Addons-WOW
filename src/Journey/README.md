# Journey Guides (`esES`)

**Prioridad:** Alta  
**Autor upstream:** `journeyaddon`  
**Metodología:** Método C — Scripts de ruta

### Reglas técnicas:
1. **Intocable (Lógica de ruta):**
   - Directivas con punto: `.goto`, `.accept`, `.turnin`, `.target`, `.hs`, `.fly`, etc.
   - Coordenadas `x, y`.
   - Identificadores numéricos de misiones y NPCs.
2. **Traducible (Texto de interfaz):**
   - Textos descriptivos de ayuda y pasos que lee el jugador.
3. **Codificación:** Guardar obligatoriamente en **UTF-8 sin BOM**.
